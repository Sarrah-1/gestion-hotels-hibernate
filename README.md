# Projet Hibernate - Gestion d'Hôtels et Chambres

Projet Java / Hibernate pour la gestion des données d'hôtels et de chambres avec requêtes HQL optimisées.

## Structure du Projet
- `src/ma/ens/entities` : Entités Hibernate (`Hotel`, `Chambre`, `TypeChambre`)
- `src/ma/ens/services` : Couche de services (`HotelService`, `ChambreService`)
- `src/ma/ens/test` : Classe de test et d'exécution (`Test.java`)
